# dentspeak
💡 What is DentSpeak?

DentSpeak is a multilingual, voice-based dental report explanation tool.
Explains dental reports in Tamil, Bengali and Hindi by voice. Built with Sarvam AI 

The workflow is simple:

📝 Patient enters their dental report
➡️
🤖 AI converts clinical terminology into simple language
➡️
🌐 Patient chooses Tamil, Bengali, Hindi, or English
➡️
🔊 DentSpeak reads the explanation aloud
➡️
➡️ Patient gets a clear next step
